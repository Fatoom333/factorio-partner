# factorio-partner

ИИ-агент (Claude) играет вторым персонажем в вашем сейве Factorio 2.0 (Space Age): ходит, добывает, крафтит
и строит по тем же правилам, что и игрок. Агент получает поручения вроде «поставь добычу на этой руде» и
работает в живом времени, пока вы играете.

## Как это устроено

```
Claude (агент) ── MCP ──> сервер (Python) ── RCON ──> игра с модом
```

- `mod/factorio-partner/` — мод (Lua): тело помощника, очередь задач, события, рефлексы.
- `server/` — MCP-сервер (Python): мост между агентом и модом по RCON.
- `agents/` — запуск помощников, стиль общения, примеры поручений; правила агента — `.claude/agents/partner.md`.
- `tools/pc/` — тестовый стенд: сервер Factorio без окна на копии сейва и живые сценарии.
- `docs/` — описание протокола, действий, событий и состояния.

Помощник — отдельный персонаж `character` без игрока в силе хозяина (владельца сейва). Агент не пишет код
игры: он вызывает готовые инструменты MCP, сервер проверяет аргументы и отправляет их моду, мод выполняет
действие и присылает события. Рефлексы (отступить от врага, возродиться) работают в самом моде, поэтому
агент может «спать» между событиями.

### Честность
- Единственный вход в игру — команда мода `/partner <JSON>` по RCON. Консольные команды `/c` и `/sc` не
  используются, поэтому **достижения сохраняются**.
- Никакого телепорта и предметов из воздуха: материалы берутся из инвентаря помощника, сундуков и с земли,
  путь проходится пешком, постройки ставятся в пределах досягаемости.
- Приказывает помощнику только хозяин; остальные сообщения в чате игры агент воспринимает как данные, а не команды.

## Что умеет
- **Восприятие:** карта вокруг, руда, склады, призраки, производство и его скорость, рецепты, поиск
  предмета по всей базе, форма суши и выходы с участка, справка как в Факториопедии, «что из чего делается
  и где это взять».
- **Движение:** ходьба с поиском пути, подход, следование за хозяином, выход из застревания.
- **Руки:** добыча (в том числе набор предмета с камней подряд), фоновый крафт, перенос предметов, сбор
  с земли, смена рецепта у стоящей машины.
- **Стройка:** постановка построек, чертежи с режимами постановки как с Shift, отсыпка и фундамент по
  свойствам плиток из игры, строительство руками или личными дронами, снос.
- **Планирование:** разметка добычи по раскладкам Mining Patch Planner и лента от добычи до базы в обход
  жидкости и построек; проектирование чертежей через factorio-forge
  (`partner_plan`), если он установлен.
- **Бой и рефлексы:** отступление и возврат к делу, заправка турелей и стрельба (по слову хозяина),
  возрождение через 10 секунд.
- **Общение:** помощник отвечает в чат игры под своим именем (настройка `partner-helper-name`), метки
  `[gps]` в чате кликаются; правила хозяина запоминаются с подтверждением в игре.
- **Несколько помощников** — число задаёт игрок при запуске.

## Быстрый старт

Нужно: Factorio 2.0 (проверено на 2.0.77), Python 3.11+, Claude Code.

1. **Мод.** Положите `mod/factorio-partner/` в папку модов игры как `factorio-partner_<версия>` (папка или
   zip с таким же именем) и включите мод.
2. **RCON.** Для игры, которую вы хостите из меню («Мультиплеер → Хост сохранённой игры»), в
   `config.ini` задайте `local-rcon-socket=127.0.0.1:27015` и `local-rcon-password=<пароль>` (или в скрытых
   настройках: Ctrl+Alt и «Настройки»). Пароль положите в файл вне репозитория: одна строка.
3. **Сервер.**
   ```powershell
   python -m venv $env:TEMP\fp-venv
   & $env:TEMP\fp-venv\Scripts\python -m pip install -e "server[dev]"
   $env:FP_RCON_PORT = "27015"; $env:FP_RCON_PASSWORD_FILE = "<путь к файлу с паролем>"
   ```
   Остальные настройки и инструменты — [server/README.md](server/README.md) и [docs/MCP.md](docs/MCP.md).
4. **Помощники.** Хозяин должен быть в игре. Скрипт спросит число помощников и вид тела, выдаст ключи,
   создаст тела и напишет конфигурацию MCP:
   ```powershell
   python agents/launch.py --helpers 1 --body character
   ```
5. **Агент.** Запустите Claude Code с конфигурацией из шага 4 (`claude --mcp-config "<FP_HOME>/launch/mcp.json"`)
   и запустите сценарий `agents/workflows/partner-play.js` — подробности в [agents/README.md](agents/README.md).

Проверки без игры и на тестовом сервере — [docs/TESTING.md](docs/TESTING.md).
